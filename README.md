# 💈 Barbearia Los Parças

## 📌 Apresentação do Projeto

A Barbearia Los Parças é uma landing page desenvolvida para divulgar os serviços de uma barbearia moderna. O projeto apresenta um visual profissional, responsivo e focado na experiência do usuário, destacando os principais serviços oferecidos, a equipe, informações de contato e identidade visual da marca.

A aplicação foi construída utilizando Sass para proporcionar uma organização mais eficiente dos estilos e facilitar futuras manutenções.

---

## ✨ Funcionalidades

- ✔️ Apresentação institucional da barbearia
- ✔️ Exibição dos serviços
- ✔️ Sessão da equipe
- ✔️ Botão para contato via WhatsApp
- ✔️ Layout totalmente responsivo
- ✔️ Interface moderna
- ✔️ Organização modular dos estilos
- ✔️ Animações durante a navegação

## 📂 Estrutura do Projeto

```text
barbearialosparcas/
│
├── images/
├── partials/
│   ├── _colors.scss
│   ├── _header.scss
│   └── _layout.scss
│
├── style.scss
├── style.css
├── style.css.map
├── script.js
└── index.html
```

### Estrutura

**images/**
- Imagens dos serviços, logotipo e demais elementos gráficos.

**partials/**
- Arquivos Sass modulares responsáveis pela organização dos estilos da aplicação.

**style.scss**
- Arquivo principal dos estilos em Sass.

**style.css**
- Arquivo CSS compilado utilizado pela aplicação.

**script.js**
- Responsável pelas interações da interface.

**index.html**
- Estrutura principal da landing page.
