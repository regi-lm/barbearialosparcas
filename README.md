# Barbearia Los Parças — redesign 2026
Site estático pronto para Vercel.

## Estrutura
- `index.html`
- `assets/css/`: CSS separado por seção + responsividade
- `assets/js/main.js`: animações e interações comentadas
- `assets/images/barbeiros/`: fotos reais de Nadson e Renato

## Fotos provisórias
As imagens remotas do Unsplash (hero, cortes e Luan) são placeholders. Para substituir, salve as fotos finais em `assets/images/` e troque os `src`/backgrounds correspondentes.

## Deploy na Vercel
Importe a pasta/repositório como projeto estático. Não há etapa de build.

## Contatos configurados
Nadson, Renato e Luan possuem links individuais de WhatsApp e Instagram. Os CTAs de agendamento já abrem conversa direta.
